# Capstone-project-Disease-Surveillance-dashboard-
HealthWatch is a user-friendly public health web application designed to help users monitor their health, access essential health information, and stay informed about preventive healthcare. the project focus on creating a simple, accessible and responsive interface using modern UI development principles.
# Project Objective
The goal of healthWatch is to provide users with a simple digital platform where they can:
-Monitor important health information
-Track personal health activities
-Access health and wellness resources
-Recieve health reminders
-Learn about preventive healthcare
-Easily navigate essential health information
#Features:
1. User Authentication - Login and registration interfaces for users
2. Health Dashboard - Overview of the users health activities and information
3. Responsive Design - Optimized for desktop, Tablet and mobile devices
